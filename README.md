## How to Use

### 1. Download from GitHub
```bash
git clone https://github.com/MrBolJ-max/-postureblend-shopify-theme.git
cd -postureblend-shopify-theme
```

### 2. Upload to Shopify
1. Go to **Online Store → Themes**
2. Click **Upload theme**
3. Select the theme folder or zip
4. Click **Publish** when ready

### 3. Replace Product Images
Upload real product photos via Shopify admin:
- `hero-lifestyle.jpg` — 1920x1080
- `product-front.jpg` — 800x1000
- `product-back.jpg` — 800x1000
- `before-after.jpg` — 1200x600
