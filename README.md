## How to Use

### 1. Upload Theme to Shopify
1. Go to **Online Store > Themes**
2. Click **Upload theme**
3. Select `postureblend-theme.zip`
4. Click **Publish** when ready

### 2. Replace Product Images

**Required images to upload via Shopify admin:**

| Image | Dimensions | Suggested filename |
|-------|-----------|-------------------|
| Hero lifestyle photo | 1920x1080 | `hero-lifestyle.jpg` |
| Product front view | 800x1000 | `product-front.jpg` |
| Product back view | 800x1000 | `product-back.jpg` |
| Product detail/zoom | 800x1000 | `product-detail.jpg` |
| Before/After comparison | 1200x600 | `before-after.jpg` |
| Size guide diagram | 800x600 | `size-guide.jpg` |
| Trust badge icons | 64x64 each | `icon-*.png` |

### 3. Update Logo
- Upload your final logo in **Theme Settings > Logo**
- Or replace `assets/logo.svg` with a PNG version

### 4. Configure Theme Settings

In **Theme Customizer**:
- Set brand colors to the palette above
- Add your store name: **PostureBlend**
- Configure announcement bar text
- Set up navigation menus
- Add payment icons

### 5. Product Page Setup

**Product details to configure:**
- Title: "FallSweet Wireless Posture Correction Bra"
- Price: $29.99 USD
- Compare-at price: $49.99 (shows savings)
- Inventory: Set realistic stock (theme shows urgency)
- Variants: Size S, M, L, XL, XXL
- Description: Use the copy from `launch-package-posture-bra.md`
